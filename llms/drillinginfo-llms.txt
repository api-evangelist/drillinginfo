# Drillinginfo (Enverus) Developer API

> Drillinginfo — now Enverus — is an Austin, Texas energy-technology company providing AI-powered analytics over the most comprehensive oil-and-gas, power, renewables, and financial-markets dataset. Its Developer API (formerly Drillinginfo Direct Access) gives subscribers read-only, token-authenticated JSON access to well, production, completion, permit, rig, wellbore, lease, and producing-entity datasets, paginated via RFC 5988 Link headers.

This llms.txt is generated by the API Evangelist enrichment pipeline from the public catalog and repo artifacts. It is not published by Enverus.

## APIs

- [Enverus Developer API (v3)](https://app.enverus.com/direct/#/api/explorer/v3/gettingStarted): Current read-only data-access API. Base URL https://api.enverus.com/v3/direct-access/. Secret-key credential exchanged for a bearer token.
- [Enverus Direct Access API (v2, legacy)](https://app.enverus.com/direct/#/api/explorer/v2/gettingStarted): Legacy version. Base URL https://di-api.drillinginfo.com/v2/direct-access/. client_id/client_secret + API key exchanged for a bearer token.

## Datasets

- wells, well-origins, wellbores, producing-entities, production, completions, permits, rigs, casings, legal-leases (query with field filters + ge/le/gt/lt/btw/in functions; JSON output)
